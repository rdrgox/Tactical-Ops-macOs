# Tactical Ops: Assault on Terror for macOS

Native macOS installers for Tactical Ops: Assault on Terror, based on the OldUnreal Unreal Tournament 469e engine.

## Compatibility

The installers were tested on both Intel-based Macs and Apple Silicon systems.

### Tested Hardware

- iMac "Core 2 Duo" 3.06 21.5" (Late 2009) 
- MacBook Pro “Core i5” 3.1 GHz, 13-inch (Mid 2017)
- MacBook Air with Apple M2, 8-core CPU / 8-core GPU, 13-inch

## Downloads

Two alternative installers are available:

- `TO340-macOS.dmg`
- `TO350-macOS.dmg`

## Installation

1. Download the desired DMG.
2. Open the DMG file.
3. Drag `UnrealTournament.app` to **Applications**.
4. Launch the application.

On first launch, the application automatically prepares the required game files in:

```text
~/Library/Application Support/Unreal Tournament/
